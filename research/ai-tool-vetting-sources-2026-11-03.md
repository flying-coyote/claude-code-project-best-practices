## Detection commands tested this session

Run against synthetic fixtures in a scratch directory (not against any real repo), GNU grep 3.x and Python 3, 2026-11-03:

- `LC_ALL=C.UTF-8 grep -nP '[\x{200B}-\x{200F}\x{202A}-\x{202E}\x{2060}-\x{2064}\x{FEFF}\x{E0000}-\x{E007F}]'` matched a planted Unicode Tag run (U+E0041) and a zero-width space, and did not match the clean line. BSD/macOS grep has no `-P`; use `ggrep` or the Python form.
- `grep -nE '^allowed-tools:.*Bash'` and ``grep -nE '(^|[[:space:]])!`'`` matched a planted skill frontmatter grant and an inline shell injection.
- The first-frontmatter-block awk loop (same shape as AUDIT-CONTEXT.md's currency check) flagged an agent file with no `tools:` key and passed one with `tools: Read, Grep`.
- A `python3 -I` reader over `.mcp.json` flagged `npx -y pkg@latest` and `npx -y pkg` as unpinned, passed `pkg@1.2.3`, and listed an `http` entry as remote.
